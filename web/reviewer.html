Find the forged, expired and inconsistent documents in an application.

Upload the application as PDFs. Docubrus reads every page, checks each document's proof of authenticity, compares facts across documents and the regulator's record, and shows exactly where each problem sits.

Drop PDF files here, or click to browse PDFs or scans, up to 15 files and 10 MB each. Scans are read with OCR (English, plus Hindi and Tamil where installed).
    Simulate an outage

    No files? Try a seeded case

    Each sample is a full 10-document application with one problem planted. One click runs it.

    1. Read

    Text and scans are read page by page. Every value is pinned to the exact box it came from.

    2. Prove

    Signatures, QR codes and issuer records show whether each document is genuine and unaltered.

    3. Compare

    Survey numbers, areas, dates and intake are cross-checked between documents and the regulator record.

    How a status is decided

    Every value gets exactly one status. The checks run in this order and the first one that applies decides. Verified is only possible when nothing above it applies, and an outage is never counted as a pass.
