🔌 Connect to Any Website

Embed Docroc verification into external portals, websites, applicant portals, or CMS platforms in seconds.

Option 1: 1-Line Embed Widget (Recommended)

Paste this single tag anywhere on your website. Docroc renders a responsive upload dropzone and verification card automatically.

<!-- Docroc 1-Line Embed Widget -->
<div id="docroc-container"></div>
<script src="/widget.js" 
        data-container="docroc-container" 
        data-theme="light"
        data-button-text="Verify Documents"></script>

Option 2: Responsive iFrame

Works in WordPress, Squarespace, Wix, or custom web portals with zero scripting.

<iframe src="/embed" 
        width="100%" 
        height="720" 
        frameborder="0" 
        style="border:none; border-radius:12px; box-shadow:0 4px 20px rgba(0,0,0,0.08);">
</iframe>

Option 3: Direct Headless REST API

Submit document multipart payloads from your backend server or custom mobile/web frontend without login cookies.

curl -X POST "/api/submissions/direct" \
  -F "applicant_name=Acme Engineering College" \
  -F "files=@fire_noc.pdf" \
  -F "files=@building_occupancy.pdf"

Option 4: Real-time Webhook Callbacks

Receive real-time JSON payloads whenever an applicant completes verification, allowing your external system to update student/institutional status automatically.
